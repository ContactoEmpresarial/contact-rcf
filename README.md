# contact-rcf

Cartão digital de Rita Costa Felix (UNICRE).

Live: https://contactoempresarial.github.io/contact-rcf/

## Ficheiros (todos na raiz, branch `main`)
- `index.html` – cartão
- `style.css` – estilo
- `rita-costa-felix.vcf` – contacto para guardar
- `qr.png` – QR code (local, sem serviço externo)
- `rita.jpg` – fotografia

Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
