# Cartão digital — Rita Costa Felix

Repositório: `ContactoEmpresarial/contact-rcf`  
URL: https://contactoempresarial.github.io/contact-rcf/

## Ficheiros
- `index.html` — página do cartão
- `style.css` — estilos responsivos
- `rita-costa-felix.vcf` — contacto para guardar no telemóvel
- `rita.jpg` — fotografia de Rita (adicionar à raiz do repositório)

## Publicar
1. Carregar os ficheiros para a raiz (`/`) do repositório `contact-rcf`, incluindo `rita.jpg`.
2. No GitHub, abrir **Settings → Pages**.
3. Em **Build and deployment**, escolher **Deploy from a branch**.
4. Selecionar `main` e `/ (root)` e guardar.
5. Aguardar a publicação em https://contactoempresarial.github.io/contact-rcf/.

O QR code aponta para o URL público do cartão e é carregado de um serviço externo.
